# A2Timers v2 — customization, i18n, installer, GitHub distribution

Date: 2026-10-05 · Builds on `2026-10-05-a2timers-overlay-design.md`

## 1. Per-event customization
Settings dialog becomes a table, one row per event: **Show** ☑, **Alert** ☑, **Sound** (combobox) + ▶ preview.
Also: language (Auto / Italiano / English), lead minutes (1–60), "check for updates" ☑.

- Show and Alert are independent. Hidden rows are removed from the overlay, which resizes.
- Sound ids:
  - `builtin:bell|gong|double|horn` — WAVs generated by `tools/make_sounds.py`, shipped in `assets/sounds/`.
  - `system:SystemNotification|SystemAsterisk|SystemExclamation|SystemHand` — Windows aliases.
  - `none`.
  - `file:<absolute path>` — user WAV chosen via "Choose file…".
  Missing/unplayable file → falls back to `system:SystemNotification`.
- Default sound per event comes from optional `"sound"` in `events.json` (else `builtin:bell`).

Settings schema (`settings.json`):
```json
{"x": 50, "y": 50, "lead_minutes": 5, "language": "auto", "check_updates": true,
 "events": {"rift": {"show": true, "alert": true, "sound": "builtin:gong"}}}
```
Legacy `"alerts": {"id": bool}` is migrated into `events[id].alert`.

## 2. i18n (it / en)
- `i18n.py`: `STRINGS[lang][key]`, `t(lang, key, **fmt)`, `detect_language()` (Windows UI language Italian → `it`, else `en`).
- Event `name` in `events.json` is either a string or `{"it": ..., "en": ...}`; lookup falls back to `en`, then first value.
- Changing language rebuilds the overlay.

## 3. Paths
- `APP_DIR`: bundle dir (`sys._MEIPASS` when frozen, else source dir) — read-only assets, default `events.json`.
- `DATA_DIR`: `%APPDATA%\A2Timers` (created on start) — `settings.json`, optional user `events.json` override.

## 4. Update check
- `updater.py`: `parse_version("v1.2.0") -> (1, 2, 0)`, `is_newer(tag, current)`, `fetch_latest(repo, timeout=5)` → `(tag, html_url) | None` via GitHub API `releases/latest`.
- Runs once on start in a daemon thread if enabled; result picked up by the Tk tick (no Tk calls from the thread).
- Newer → clickable "⬆ vX.Y.Z" label in the header opening the release page. Any error → silent.
- `version.py` holds `__version__` and `GITHUB_REPO`.

## 5. Toasts
- Installed build: Start-menu shortcut registers AppUserModelID `A2Timers.Overlay`; toasts use it (sender shows "A2Timers"). Dev/run-from-source: PowerShell AUMID as today.
- Process calls `SetCurrentProcessExplicitAppUserModelID("A2Timers.Overlay")`.

## 6. Packaging
- PyInstaller onedir, windowed, icon `assets/icon.ico` (generated by `tools/make_icon.py`), data: `events.json`, `assets/`.
- Inno Setup (`installer/A2Timers.iss`): per-user (`PrivilegesRequired=lowest`), `{localappdata}\Programs\A2Timers`, Start menu shortcut with AUMID, optional desktop icon and "start with Windows" (HKCU Run), uninstaller. Output `dist/A2Timers-Setup-<version>.exe`.
- `build.ps1`: make assets → PyInstaller → ISCC.
- GitHub Actions `release.yml`: on tag `v*` build on `windows-latest`, run tests, attach Setup.exe to the release.
- README (it/en), MIT LICENSE, "not affiliated with NCSOFT" disclaimer, SmartScreen instructions.
